# Agents file

Rules for working on this project.

## Writing rules

- No emdashes
- No emojis
- No lines that only contain `>` or `/>`
- Code and comments in English
- Page content in Italian

## Git rules

- Never commit without asking for permission first
- Commit messages are minimal and only contain the important info
- Keep commit messages short and to the point, average of 12 words per commit
- Example commit messages: `added crud`, `removed tailwindcss`

## Process rules

- Call phases sessions
- No Prettier or other unnecessary tooling, keep a minimalistic approach to code
- Ask before adding dependencies that are not required

## Project rules

- Client: Giulia Ursino, psychologist
- Style: simple, clean, beach and sea colors
- Stack: React and Express
- Deployment: GitHub Pages first for client review, then final hosting based on client preference
